# Assets

- `icons/`: technology logos; theme variants are in `icons/light/` and `icons/dark/`. Shared color logos are stored once.
- `contacts/`: light and dark contact icons.
- `licenses/`: original MIT and CC0 licenses.

The README uses GitHub's supported [picture element](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/quickstart-for-writing-on-github) to select light and dark images. Captions are plain text beneath each logo.

Ready-made themed logos come from [Skill Icons](https://github.com/LelouchFR/skill-icons), pinned to 5401d691a2268d5a3ee6c3b3163c31b6a2a0be6d. Codex comes from [Lobe Icons](https://github.com/lobehub/lobe-icons), pinned to bcdb7c82792a854c2967f7328e11a30205ea584d. InfluxDB and JetBrains use Devicon v2.17.0 artwork; contact icons reuse Simple Icons 16.35.0. Brand names and logos belong to their respective owners.

Live profile views, followers and statistics remain remote so that their numbers update.
